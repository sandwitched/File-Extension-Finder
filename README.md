# File Extension Finder
Scans C Drive for a specific file type and saves it in a .csv

### Only for Windows

## Requirements
You need Python 3.4 or higher, you can download Python from [here](https://www.python.org/downloads/)

## Installation
### .EXE installation
Run the .EXE by going to your Downloads folder, then double-clicking it with your left mouse button.

It will ask you where to install the files.

<img width="380" height="153" alt="Select Files" src="https://github.com/user-attachments/assets/33735612-f660-422e-abae-e585875678fa" />

Once you select the path, press Extract,
now go in the folder that you installed the app on (called File-Extension-Finder-X.X.X)(the Xs are placeholders), then left-click on the code folder, then right-click on the code folder twice, when the dropdown menu shows up, press Ctrl+Shift+C or Copy as path in the dropdown menu.

Now open up CMD, and type in:
```python
python
```
then put a space, then paste in the path with Ctrl+V or right-click on the mouse inside the CMD window.
Now press enter, and now you're done!

### .ZIP installation
Extract the .ZIP before continuing.

To run the script, do these commands.
```cmd
cd /d %USERPROFILE%\Downloads\File-Extension-Finder-main\File-Extension-Finder-main\code\
```

```python
python main.py
```
